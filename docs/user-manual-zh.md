# 用户使用手册

本文说明 Go 合并版 Map Tile Fetcher 的实际使用方式。

## 1. 启动应用

进入 Go 应用目录：

```powershell
cd apps/admin-region-tiler
npm ci --omit=dev --no-audit --no-fund
go run .
```

浏览器打开 `http://127.0.0.1:8081/`。

本地默认登录账号：

- 用户名：`admin`
- 密码：`adminmap`

可信本地环境可以通过 `AUTH_ENABLED=false` 关闭登录。部署环境建议保持登录启用，并通过本地环境变量或部署密钥覆盖默认用户名和密码。

## 2. 服务凭证

页面中的 **服务凭证** 区域同时用于行政区划下载和范围框选下载。

- **天地图 Token**：替换天地图源 URL 中的 `YOUR_TIANDITU_TOKEN`，选择天地图预览底图时也使用该字段。
- **Mapbox Token**：替换 Mapbox 源 URL 中的 `YOUR_MAPBOX_TOKEN`。
- **Mapbox SKU**：填写后替换 `YOUR_MAPBOX_SKU`；不填写时会移除该 SKU 查询参数。

凭证会用于任务创建和预览注册，任务数据库保存所需的地图源 URL。预览凭证提前
60 秒自动续期，退出登录或修改凭证会清空旧缓存。不要把真实 token、`.env`、
运行数据库、下载瓦片或生成压缩包提交到 Git。

## 3. 行政区划下载

当目标区域已有维护好的 GeoJSON 区域文件时，使用该模式。

1. 选择 **行政区划下载**。
2. 输入任务名称。
3. 在服务凭证区填写所选地图源需要的 token。
4. 选择地图源提供方，并勾选一个或多个图层。
5. 配置行政区划级别。默认从全球、中国开始，再按已维护数据选择省、市、区县。
6. 设置下载线程、保存线程、请求间隔、产物格式和执行时间。
7. 查看页面内摘要后点击创建；提交期间按钮禁用，避免重复任务。

系统会创建一个父任务，并按所选图层创建子任务。每个图层作为同一父任务下的一个子任务运行。

## 4. 范围框选下载

当目标区域需要在地图上直接选择时，使用该模式。

1. 选择 **范围框选下载**。
2. 输入任务名称。
3. 在公共来源目录选择所需地图或高程源，需要凭证的来源再填写对应字段。
4. 可用天地图快捷项选择影像、注记、矢量或地形底图；也可直接选择其他来源。
5. 选择矩形或多边形绘制模式。
6. 在地图上点击选择范围：
   - 矩形：点击两个对角点。
   - 多边形：至少点击三个点。
7. 确认或手动调整坐标和层级。
8. 查看瓦片估算、产物格式和执行时间。
9. 查看页面内摘要后创建；线程、保存线程和间隔均按页面值提交。

范围坐标统一使用 WGS84 经纬度，瓦片方案使用 Web Mercator。

## 5. 计划任务

每个任务支持两种执行方式：

- **立即执行**：创建后立即进入队列。
- **单次定时**：到达选择的本地时间后执行。

立即、定时和失败重试统一进入持久化队列，显示 `queued`。默认最多同时运行
3 个子任务，第 4 个开始排队。暂停释放执行槽，恢复需要等待可用槽位。
异常退出后自动继续原运行，检查已保存结果后只补缺失或损坏瓦片；手动暂停保持暂停。
下载、转换及打包阶段中断会重新进入对应处理，旧 worker 退出后新 worker 才接管。

默认每个父任务所有来源合计最多 100 万个唯一请求。行政区、多边形和重叠区域先显示
估算，在“准备”阶段去重后按实际数量判断；只有真实超额才需要缩小范围或层级。
高程请求包含祖先及共享边界采样的邻接源。线程默认 3，可选 1～50，来源并发上限可能进一步
降低实际线程；实际间隔不低于来源最低值。任务详情显示生效参数。

## 6. 产物格式

创建任务时可以选择：

- **ZIP 文件树**：瓦片先写入文件系统，再打包为 ZIP 产物。
- **MBTiles**：直接生成 MBTiles，并作为产物下载。
- **Cesium 地形**：使用 Terrarium 高程生成离线 quantized-mesh ZIP，支持应用内三维预览。

地形底图是普通地图图片，继续选择 ZIP/MBTiles；Mapbox 地形矢量不是高程。
真实高程选择“公开高程 Terrarium”，最大层级默认 14、允许 15，不需要 AWS 账号。
完成后从子任务打开三维预览或下载 ZIP。具体结构、离线服务和精度限制见[地形说明](terrain.md)。
预览静止时避免持续重绘；移动视角和切换高程设色会正常更新，画质不变。

产物按任务和运行 ID 隔离存储，同名任务不会覆盖。控制数据库仅保存索引和状态；
MBTiles 产物自身使用独立 SQLite 文件保存瓦片。新产物发布成功前，下载入口继续
提供上一份已发布产物，打包、取消或空间不足不会替换旧入口。

## 7. 任务管理

任务列表默认每页 50 个父任务，可翻页和按状态筛选；计数来自全部历史。
仅可见任务页每五秒刷新，返回页面立即刷新；后台刷新保留已有内容、焦点、选择和展开状态。
阶段包含准备、下载、转换、校验、打包和发布，累计完整度与本次运行进度分别显示。

可用操作取决于任务状态：

- 暂停运行中任务。
- 恢复已暂停任务。
- 取消计划中、等待中、运行中或已暂停任务。
- 删除已完成、失败、部分失败或已取消任务。
- 产物 ready 后下载产物。
- 存在可重试失败记录时，重试失败瓦片。

删除父任务会清理子任务、历史运行、产物、失败记录和关联元数据。活跃、暂停或
打包任务需要先取消并等结束。内置 GeoJSON 永不删除，生成区域文件在最后一个
引用解除后清理。删除失败会保留清理进度，可再次执行删除。

## 8. 失败记录与重试

瓦片下载失败时，系统会持久化可重试失败记录，并在任务响应和失败记录接口中展示。

**重试失败瓦片** 先复制可用旧结果，再补未解决的可重试瓦片，最终 ZIP/MBTiles
包含旧成功瓦片和新补齐瓦片。历史失败事件保留，已解决事件不再计入当前失败数。
详情分别显示本次运行进度和累计完整度，仍有缺口时不会显示全部完成。

历史任务可选择 **核对本地产物**，此操作只检查本地文件，不发起地图下载。
重试先入队，由 worker 校验基线；旧成功瓦片丢失或损坏时运行显示基线错误，选择
**重新创建完整任务** 主动重下。系统不会隐式把失败重试扩大成全量下载。
首次地形根瓦片失败时，可复用仍在的有效原始高程缓存补齐。
空间检查按复制和打包阶段所需的额外字节计算，不强加固定 1 GiB；
`task.min_free_disk_bytes` 可显式设置本地保留空间。新请求大小无法预知，实际写盘错误仍会报告。

常见失败类型：

- `429`：请求频率过高。
- `418` 或 blocked 分类：当前出口 IP 可能被地图源拦截。
- `502`、`503`、`504`：上游服务不稳定。
- proxy 或 network 分类：本地网络或代理链路异常。

出现限流或拦截时，建议增大请求间隔、降低线程数，或更换出口/代理。

## 9. 本地文件与安全

以下内容不得进入 Git：

- `.env`
- `data/`
- `output/`
- `tiles/`
- `bin/`
- `obj/`
- `publish*/`
- 日志、数据库、压缩包、二进制、临时运行截图和下载瓦片

正式脱敏文档图片允许放入 `docs/assets/`，使用本地夹具并记录可重复生成命令。

文档和示例中允许保留的占位符：

- `YOUR_TIANDITU_TOKEN`
- `YOUR_MAPBOX_TOKEN`
- `YOUR_MAPBOX_SKU`

## 10. 维护者验证

发布或交付前执行：

```powershell
cd apps/admin-region-tiler
npm ci --no-audit --no-fund
npx playwright install chromium
node .\scripts\release_preflight.mjs
```

发布预检会运行 Go 测试、前端语法检查、浏览器 UI 冒烟、敏感信息扫描和生成物扫描。

配置、迁移方法、接口兼容及逐项证据见 [本轮升级记录](upgrade-2026-11.md)和[源码仓库的验证链路](https://github.com/Joe5027/map-tile-fetcher/blob/main/docs/validation-chain.md)。

## 账号密码维护

登录后从账号菜单选择“修改密码”。忘记密码时由维护者执行离线恢复，详见
[密码修改与离线恢复](password-recovery.md)。修改初始账号配置不会重置已有用户。
